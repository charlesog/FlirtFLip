## 🎯 Descripción

FlirtFLip es una aplicación móvil innovadora que te permite conocer personas nuevas de una manera divertida y segura. Con una interfaz intuitiva y características diseñadas para facilitar conexiones genuinas, FlirtFLip cambia la forma en que las personas se relacionan en la era digital.

## ✨ Características Principales

- 🎪 **Sistema de Descubrimiento Inteligente** - Encuentra perfiles que realmente te interesan
- 💬 **Chat en Tiempo Real** - Comunícate con tus conexiones al instante
- ❤️ **Sistema de Likes** - Expresa tu interés de forma clara y directa
- 🔒 **Seguridad y Privacidad** - Controla quién ve tu perfil y tus datos
- 📍 **Ubicación Inteligente** - Descubre gente cerca de ti (opcional)
- 🎨 **Diseño Moderno** - Interfaz atractiva y fácil de usar
- ✅ **Verificación de Identidad** - Perfiles auténticos y seguros

## 🚀 Comenzando

### Requisitos Previos

- Android 14 o superior
- Conexión a Internet
- Una cuenta de correo válida

### Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/charlesog/FlirtFLip.git
cd FlirtFLip
```

2. Abre el proyecto en Android Studio:
```bash
File > Open > (Selecciona la carpeta del proyecto)
```

3. Compila y ejecuta:
```bash
./gradlew build
./gradlew installDebug
```

## 🛠️ Stack Tecnológico

### Frontend
- **Kotlin** - Lenguaje de programación principal
- **Jetpack Compose** - UI moderno y declarativo
- **Material Design 3** - Sistema de diseño de Google

### Backend & Base de Datos
- **Firebase** - Autenticación, Firestore, Storage
- **Retrofit** - Cliente HTTP para APIs REST
- **Room** - Base de datos local

### Librerías Principales
- **Coroutines** - Programación asincrónica
- **Hilt** - Inyección de dependencias
- **Navigation** - Navegación entre pantallas
- **Coil** - Carga eficiente de imágenes
